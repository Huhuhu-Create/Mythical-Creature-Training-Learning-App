# 神兽养成 · 学习小游戏（PHP 版）

通过做**语文 / 数学 / 英语**题目来培养神兽的网页小游戏（单人本地使用，零外部依赖，PHP 驱动）。

## 运行方式
**方式一（推荐）**：双击 `start.bat`
- 自动启动 PHP 内置服务器，浏览器打开 `http://localhost:8080`，关闭服务器窗口即停止。

**方式二（命令行）**：
```
cd D:\QClaw\1112
php\php.exe -S localhost:8080 -t . router.php
```
> 本项目已自带 PHP 8.4.25（`php/` 目录），无需另行安装、无需配置 PATH、无需数据库。

## 题库（重点）
所有题库放在 **`D:\QClaw\1112\banks\`** 文件夹下，每个 `.json` 文件即一份题库，放入后**重启服务器**即自动加载，无需改代码。

支持的题库 JSON 结构（与你提供的格式一致）：
```json
{
  "题库信息": {
    "名称": "小学一年级数学上册选择题题库",
    "版本": "1.0",
    "学科": "数学",
    "年级": "一年级",
    "适用教材": "人教版",
    "题目总数": 34,
    "创建日期": "2026-04-06",
    "说明": "……",
    "学期": "上册"
  },
  "题目": [
    {
      "id": 1,
      "类别": "10以内加减法",
      "难度": "基础",
      "题干": "3 + 4 =（ ）",
      "选项": { "A": "6", "B": "7", "C": "8" },
      "答案": "B",
      "解析": "3加4等于7。",
      "知识点": ["10以内加法"]
    }
  ]
}
```
- 选项支持 `{A,B,C,D}` 对象，也兼容数组；答案填字母（如 `"B"`）或下标数字均可。
- 文件里也可只放**纯题目数组**（无 `题库信息`），系统会按文件名作为题库名。

### 年级 / 学期 范围
- 年级：一年级 ~ 六年级
- 学期：上册 / 下册
- 选用题库时按 **学科 + 年级 + 学期** 自动匹配；主页可选择筛选，并列出命中的题库信息。

> 示例：`banks/sample_一年级数学上册.json`（3 题，供参考格式）。

## 玩法
- 主页选学科（语文📖 / 数学➗ / 英语🔤），可再选年级、学期，每次随机抽 5 题。
- 答对得经验 +12、金币 +6；答错得经验 +3（展示 类别 / 难度 / 知识点 / 解析）。
- 神兽随经验进化：🥚→🐣→🐉→🐲→✨🐲。
- 金币喂食提升心情/饱食；长时间不学习会缓慢下降。改名、重新开始均即时存档。

## 文件结构
- `router.php` — PHP 路由器（静态页 + `/api/load`、`/api/save`，自动扫描 banks/）
- `php/` — 自带 PHP 8.4.25 运行环境
- `public/` — 前端（index.html / style.css / app.js）
- `banks/` — **你的题库文件夹（放这里）**
- `data/state.json` — 神兽状态 + 学习进度
- `reset.php` — 重置进度（`php\php.exe reset.php`）
- `start.bat` — 一键启动

## 接口
- `GET /api/load?subject=数学&grade=一年级&term=上册` → `{ state, banks, questions }`
- `POST /api/save`（body 含 `state`）→ 写入 `data/state.json`
